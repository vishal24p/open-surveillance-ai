# Skills and Plugins

Project workflow only. Not runtime dependencies.

- Ponytail: smallest safe implementation.
- Caveman: concise collaboration.
- `grill-me` and `grilling`: settle feature scope before behavior changes.
- Superpowers `writing-plans`: plan multi-step work before code.
- Superpowers `executing-plans`: implement approved plans.
- Superpowers `verification-before-completion`: fresh evidence before completion claims.
- ECC `coding-standards`: readable, minimal, tested code.
- ECC `fastapi-patterns`: only when an HTTP API exists.

Installed workflow plugins: Superpowers, ECC, and Caveman. No external app plugin is needed for the DroidCam camera milestone.
