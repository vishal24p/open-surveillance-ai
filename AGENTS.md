# Agent Instructions

Project scope, milestones, technical constraints, and operating commands live in `MILESTONES.md`, `README.md`, `HANDOFF.md`, and `docs/`.

## Behavior

- Read the relevant flow before editing it.
- Use `MILESTONES.md` as the source of truth for the current implementation slice.
- Ask for a design decision when requested work changes that scope.
- Add one runnable check for non-trivial logic.
- Verify commands and outputs before claiming completion.
- Keep unrelated files and user changes untouched.
